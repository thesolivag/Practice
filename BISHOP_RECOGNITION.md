# Bishop recognition study

Built as an isolated recognition mode, not a replacement for baseline paper orders or the existing RR study. Entry rules setting `bishop_flow_study` defaults on. No broker orders, paper fills, Telegram messages or performance statistics are generated by this mode.

## Sequence

1. Current watched, confirmed web bias. Conflicting directions block admission. A bias confirmed after the H4 break cannot sponsor that break.
2. Proved H4 closed break: exact A/V reference, availability before the break candle, old opposing role, flipped role at close, close beyond that exact level. A wick-only break, absent reference or ambiguous link is rejected. This strict A/V interpretation is narrower than every Bishop structural route; unsupported routes are not silently accepted.
3. Potential inducement is frozen when its H4 candle closes. Reuses the explicitly experimental later-KL approach rule from Bishop's archive. It may be the next candle or a later candle; there is no next-candle requirement. The candidate is formed without testing its future sweep. It remains bound to its parent and chosen key level.
4. First actual liquidity take on closed H1/H2/H3 evidence. An intervening gap or broken episode invalidates the watch.
5. Actual contact with the linked H4 key level and a close back on the directional side, with the correct role and first-take lineage. The take and reaction can occur on the same child candle; a candle close after the contact is observable, but no finer intrabar chronology is invented.
6. Existing Bishop breakout, engulfing or 4th-man setup must explicitly name the same pool, parent, level and reaction. No replacement confirmation family. Its close must be available before promotion. Existing internal story qualification still applies. Current study stop proof provides independent 1R/2R/3R proposed geometry. Missing stop/target qualification remains unresolved.

A CONFIRMED_PLAN is not an order, fill, win or selected portfolio position. Original strategy targets/stops, its bias gate and the RR results cohort remain untouched. No archive orders are backfilled into this mode.

## Persistence and web

Dedicated user/pair `bishop_flow_state` table; explicit ownership on every read/write. Fresh activation timestamp; selected markets only. Shared feed lock, fair rotation, separate100-second job and20-second child timeout. No eligible web bias skips engine work. Stale scans retain prior evidence with a stale marker. Changed prior stage history becomes EVIDENCE_CHANGED rather than silently rewriting it. Completed plan evidence freezes. Retention is all live watches plus latest100completed/retired records per market; UI shows latest50 across markets. This is not an all-history performance cohort. Disabling the setting pauses the recognition scanner.

Entries → Bishop recognition study shows stage times, broken level and close, liquidity and key level, confirmation type, proposed prices, rejected breaks and scan status. API `/api/bishop/recognition` requires authentication and scopes by user. The original later-liquidity switch stays disabled in baseline; this separate runner enables it only inside its own detector, and blocks every order before simulation.

## Verification and limits

Tests cover prospective candidates before sweeps, delayed stages, closed versus wick-only breaks, future/contradictory bias, missing candles, role loss, exact confirmation lineage, future appended bars, BUY/SELL symmetry, immutable prior stages, private API, MySQL ownership and browser display. Frozen EURNZD integration uses an explicitly synthetic test bias; it does not prove historical KK alignment or teacher-trade identity. Source-derived later approach geometry and closest usable KL association remain implementation choices. No universal teacher validation or profitability claim.

Local verification: 54 focused tests passed, 2 optional MySQL tests skipped; browser suites passed. Frozen EURNZD integration completed in 5.78 seconds using a synthetic test bias. A 12-hour prefix comparison preserved all 33 prior stage events after fixing an invalid cross-timeframe segment-counter comparison. This is one causal replay, not teacher validation or profitability evidence.
